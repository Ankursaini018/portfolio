# Project Architecture Rules

- Use semantic dark Diroz-inspired tokens and Inter Tight across the public portfolio, because the Diroz reference supersedes the earlier editorial direction.
- Keep each resume category in its own public section, because the user explicitly rejects mixed or mashed-up content.
- Use the user's three suit portraits as switchable layered cutouts with CSS depth and pointer-responsive motion rather than embedding the reference site's proprietary assets, because the visual interaction should remain original and maintainable.
- Preserve authentication, admin authorization, and contact submission logic when restyling public-facing components, because those workflows are production features.
